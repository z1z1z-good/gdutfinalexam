# 广工期末真题 & 复习资料库

广东工业大学部分课程的期末真题、复习资料与选课经验，按课程分文件夹存放，欢迎自取，仅供复习参考。

## 📂 资料目录

| 课程 | 内容 |
| --- | --- |
| [高数](./高数) | 历年期末试卷及答案（18-19、21、22-23 等）、章节练习 |
| [线代](./线代.zip) | 线性代数资料打包（zip） |
| [复变](./复变打包.zip) | 复变函数资料打包（zip） |
| [概率论](./概率论) | 2017–2023 历年试卷及答案 |
| [大物](./大物) | 13–17 年等历年期末试卷 |
| [电路](./电路) | 2008–2015 年试卷（部分无答案） |
| [数电](./数电) | 《数字电子技术》期末试卷与练习题 |
| [电磁学试卷](./电磁学试卷) | 电磁学 / 电磁场与电磁波历年试卷 |
| [半导体物理](./半导体物理) | 真题 + 习题课讲义 |
| [数字集成电路设计](./数字集成电路设计) | 19 年 A 卷、复习课与章节课件 |
| [思修，思想道德与法制](./思修，思想道德与法制) | 单选 / 多选 / 填空题库 |
